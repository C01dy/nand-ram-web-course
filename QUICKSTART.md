# 🚀 Быстрый старт

## За 3 шага к запуску

### 1. Установите зависимости
```bash
bun install
```

### 2. Запустите dev сервер
```bash
bun run dev
```

### 3. Откройте в браузере
```
http://localhost:5173/
```

## 🎮 Как пользоваться

### Навигация
1. Используйте **боковое меню** слева для выбора раздела
2. Разделы идут по порядку от простого к сложному
3. Рекомендуется изучать последовательно

### Интерактивность
На каждой странице есть интерактивные элементы:

- **PLAY** (▶) - автоматическое воспроизведение
- **PAUSE** (⏸) - остановка
- **STEP** (⏭) - один шаг вперед
- **RESET** (↻) - сброс в начальное состояние
- **Speed slider** - изменение скорости анимации

### Переключение языка
Нажмите кнопку **RU/EN** в правом верхнем углу

## 📚 Разделы

### 1. Память компьютера
**Что изучим:** Иерархия памяти (регистры → RAM → диск)
**Интерактив:** Клик на уровни памяти

### 2. Генератор тактовых частот
**Что изучим:** Clock signal, частота, период
**Интерактив:** Анимация прямоугольной волны

### 3. Tick-Tock цикл
**Что изучим:** Двухфазный тактовый цикл
**Интерактив:** Пошаговое выполнение фаз

### 4. D Flip-Flop
**Что изучим:** Основной элемент памяти
**Интерактив:** Изменение входа D, наблюдение Q

### 5. Bit микросхема
**Что изучим:** 1-битный регистр с LOAD
**Интерактив:** Управление IN и LOAD сигналами

### 6. 16-битный Register
**Что изучим:** Параллельное хранение 16 бит
**Интерактив:** Ввод значений, просмотр в разных форматах

### 7. RAM
**Что изучим:** Адресация памяти
**Интерактив:** Запись/чтение по адресам

### 8. Program Counter
**Что изучим:** Счетчик команд процессора
**Интерактив:** Операции inc/load/reset

## 💡 Советы

### Для лучшего понимания:
1. **Начните с первой страницы** - концепции строятся друг на друге
2. **Используйте STEP** - пошаговое выполнение помогает понять детали
3. **Экспериментируйте** - меняйте значения и наблюдайте результат
4. **Читайте описания** - каждая страница содержит объяснения

### Горячие клавиши:
- Пока не реализованы, но можно добавить:
  - `Space` - Play/Pause
  - `→` - Step
  - `R` - Reset
  - `L` - Toggle Language

## ❓ Проблемы?

### Приложение не запускается
```bash
rm -rf node_modules bun.lock
bun install
bun run dev
```

### Стили не применяются
Перезапустите dev сервер (Ctrl+C, затем `bun run dev`)

### Изменения не видны
Очистите кэш браузера (Ctrl+Shift+R)
