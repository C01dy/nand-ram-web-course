# NAND to Tetris Interactive Guide 🖥️

Интерактивный веб-гайд для изучения концепций из книги "From NAND to Tetris" с визуализацией работы DFF, Registers, RAM и других компонентов компьютерной памяти.

## 🎨 Особенности

- **Хакерский ретро-стиль**: Черно-зеленая цветовая схема с эффектом CRT-монитора
- **Интерактивные визуализации**: Пошаговое выполнение и анимации всех процессов
- **Двуязычность**: Переключение между русским и английским языками
- **8 разделов**: От основ памяти до Program Counter
- **Responsive дизайн**: Адаптивный интерфейс для разных устройств

## 📚 Разделы

1. **Память компьютера** - Иерархия памяти (регистры, RAM, диск)
2. **Генератор тактовых частот** - Визуализация clock signal
3. **Tick-Tock цикл** - Двухфазный тактовый цикл
4. **D Flip-Flop (DFF)** - Основной элемент последовательной логики
5. **Bit микросхема** - 1-битный регистр с load signal
6. **16-битный Register** - Параллельное хранение 16 бит
7. **RAM** - Адресация и работа с памятью
8. **Program Counter (PC)** - Счетчик команд с операциями inc/load/reset

## 🚀 Установка и запуск

### Требования

- [Bun](https://bun.sh/) (рекомендуется) или Node.js 18+

### Установка зависимостей

```bash
bun install
```

### Запуск dev сервера

```bash
bun run dev
```

Приложение будет доступно по адресу: http://localhost:5173/ (или другой порт, если 5173 занят)

### Сборка для продакшена

```bash
bun run build
```

### Предпросмотр production сборки

```bash
bun run preview
```

### Деплой на GitHub Pages

```bash
bun run deploy
```

Подробная инструкция по деплою: [DEPLOY.md](DEPLOY.md)

## 🎮 Использование

1. Выберите раздел в боковом меню
2. Читайте описание концепции
3. Используйте интерактивные элементы:
   - **PLAY** - автоматическое выполнение
   - **PAUSE** - остановка
   - **STEP** - пошаговое выполнение
   - **RESET** - сброс в начальное состояние
4. Переключайте язык кнопкой RU/EN в шапке
